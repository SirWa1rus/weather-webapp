# Weather Lookup Web Application

### What the program does
This program lets the user select a city from a predetermined list of cities and a date between 11/10/2025-11/10/2026 and outputs the following details about the weather in that city on that day:

  - high/low temperature (in Fahrenheit)
  - weather condition(s)
  - sunrise/sunset times
  - hourly temperature (in Fahrenheit)
### Commands to Run

Run these in git bash in the following order:

  1. "pip install -r requirements.txt" (RUN ONCE)
  2. "python fetch_data.py" (RUN ONCE)
  3. "python -m pytest" ---> runs tests
  4. "python app.py" ---> starts the web app
