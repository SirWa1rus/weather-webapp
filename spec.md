# What it does

    The program will ask the user to input a location (Chicago, Philadelphia, London, etc) and the program will provide with these details about the weather in the inputted area:

        -   hourly weather (in fahrenheit)
        -   the hi and lo of the day (in fahrenheit)
        -   if its raning, thundering, storming, etc.
        -   if there is a natural disaster present
        -   sunrise/sunset time
        -   if its cloudy, sunny, partly cloudy, etc.

# Specifications

    -   web app built in python
    -   https
    -   dark gray bg
    -   curved squares that containing the info + shape of search bar
    -   OpenWeather api
